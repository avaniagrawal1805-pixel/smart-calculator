# Smart Calculator 🧮

A beginner-friendly calculator built using Python.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Handles invalid user inputs
- Prevents division by zero
- Menu-driven interface

## Technologies Used
- Python 3
- VS Code

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python3 main.py
```
